# Glosario de comandos, menus y conceptos

| Termino | Explicacion clara | Ejemplo de uso |
|---|---|---|
| IDE | Entorno de Desarrollo Integrado. Programa que permite escribir, organizar, ejecutar y probar codigo. | Visual Studio Code. |
| Panel del explorador | Zona donde se ven carpetas y archivos del proyecto. | Abrir la carpeta `src`. |
| Editor de codigo | Area donde se escribe y modifica el programa. | Editar `produccion_finca.py`. |
| Terminal | Espacio para escribir comandos de texto y ejecutar programas. | `python src/produccion_finca.py` |
| Consola | Area donde se muestran resultados, mensajes o errores del programa. | Resultado total de leche. |
| Menu Archivo / File | Menu para abrir carpetas, crear archivos y guardar cambios. | `File > Open Folder`. |
| Menu Terminal | Menu para abrir o administrar la terminal integrada. | `Terminal > New Terminal`. |
| Guardar | Accion para conservar los cambios hechos en un archivo. | `Ctrl + S`. |
| Ejecutar | Poner en funcionamiento un programa para revisar sus resultados. | Ejecutar el archivo Python. |
| Comando | Instruccion escrita para que el computador realice una accion. | `python archivo.py`. |
| Atajo de teclado | Combinacion de teclas para hacer una accion rapidamente. | `Ctrl + F` para buscar. |
| Variable | Espacio donde se guarda un dato que puede cambiar. | `total_leche = 0`. |
| Ciclo | Estructura que repite instrucciones varias veces. | `for dia in range(1, dias + 1)`. |
| Condicional | Estructura que toma decisiones segun una condicion. | `if promedio < limite`. |
| Error de sintaxis | Error por escribir mal una instruccion del lenguaje. | Olvidar dos puntos despues de un `if`. |
| Error logico | Error donde el programa ejecuta, pero el resultado no es correcto. | Promedio mal calculado. |
| Depuracion | Proceso de encontrar y corregir errores. | Revisar mensajes de la terminal. |
| `python src/produccion_finca.py` | Comando para ejecutar el programa Python desde la terminal. | Se usa en la raiz del proyecto. |
| `cd carpeta` | Comando para entrar a una carpeta desde la terminal. | `cd src`. |
| `dir` | Muestra archivos y carpetas en Windows. | Verificar si existe `src`. |
| `ls` | Muestra archivos y carpetas en Linux o macOS. | Verificar archivos del proyecto. |
| `cls` | Limpia la terminal en Windows. | Borrar mensajes anteriores. |
| `clear` | Limpia la terminal en Linux o macOS. | Borrar mensajes anteriores. |
